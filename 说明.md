数据库初始化步骤：
  数据库初始化步骤

  在 Linux 上执行（需要 Python 环境）：

  cd /root/xujun/TDD-auto-platform/backend

  # 1. 安装依赖
  pip install -r requirements.txt

  # 2. 生成初始迁移（从模型自动生成）
  alembic revision --autogenerate -m "initial"

  # 3. 执行迁移（创建所有表）
  alembic upgrade head

  如果没有 Python 环境，可以用 Docker 临时容器执行：

  cd /root/xujun/TDD-auto-platform

  # 用后端镜像执行迁移
  docker compose run --rm backend alembic revision --autogenerate -m "initial"
  docker compose run --rm backend alembic upgrade head

  两种方式选一种即可。执行完后数据库表就创建好了。
